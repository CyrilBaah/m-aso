# m’aso

Live captions, typed replies and a private record of what was agreed, for Deaf and hard-of-hearing colleagues.

| Folder | What it is |
|---|---|
| `web/` | Next.js app: every screen, built on the m’aso design system |
| `ai/` | Python service: faster-whisper for captions, Gemma for summaries (coming next) |

## Run the web app

```bash
cd web
npm install
npm run dev
```

Open http://localhost:3000.
